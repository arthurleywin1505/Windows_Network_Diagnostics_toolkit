# Network Concepts Covered

## IP Address
A logical address used to identify an interface on an IP network.

## Subnet Mask / Prefix
Defines which part of an IP address represents the network and which part identifies a host.

## Default Gateway
The router a host uses to forward traffic to destinations outside its local subnet.

## DNS
The Domain Name System resolves hostnames to IP addresses. This project tests name resolution for a configured hostname.

## ICMP / Ping
Ping uses ICMP echo messages to test whether a destination responds. Replies may be blocked, so interpret results carefully.

## Latency
Round-trip response time, usually measured in milliseconds. A ping sample is a simple indicator and not a complete performance measurement.

## Routing Table
Contains routes that Windows uses to decide where to send packets.

## TCP Connections
`netstat` shows local and remote endpoints, connection states, and process IDs on Windows. This project captures a limited sample for review.
